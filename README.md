## In English

IT Supervisor and Solutions Developer, Saudi Arabia. 12+ years in IT.

I build systems for real operational problems: automating 1,800+ devices, bridging a web page to a Bluetooth thermal printer, and AI agents that verify their own work.

Every repository here is a **case study** — the problem, the engineering decision, and the result in numbers. Each has an English README.
